# Changelog

## 1.0.0 — 2026-10-09

First public release of Beep Source for Apple Silicon, macOS 14.2+.

- Application and process sound detection with Core Audio process taps.
- Local history with timestamps, durations and peak digital signal levels.
- Menu bar background operation, pause, search, short-sound and recent-event filters.
- CSV export, optional launch at login and 30-day / 5,000-event retention.
- Global fallback for unidentified audio, with documented attribution limits.
- Developer ID signature through G2, successful Apple notarization and attached ticket.
- Russian app interface, English/Russian documentation and download pages.
